# For Emma, Forever Ago · 逐句对照

Trevor Hagen 于 April Base 写下的十周年文章（2017 年 9 月）的中英对照阅读页。

- 全文 195 个句段，保留英文顺序和原段落。
- 双语对照、英文、中文三种显示方式。
- 点击句子编号进入逐句专注模式，使用左右方向键翻句。
- 对所提供文本中的疑误、残句和歧义附有译注。
- 适配手机与电脑；无外部资源和构建依赖。

## 本地使用

下载 `index.html` 并在浏览器中打开即可离线阅读。

## GitHub Pages

在仓库 Settings → Pages 中，选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`。
